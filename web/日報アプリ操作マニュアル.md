# 札幌中野冷機 業務日報アプリ 操作マニュアル

**【試験運用版】このマニュアルは最初にお試しいただく3名様向けの案内です。**
使ってみて分かりにくい点・改善したい点があれば、遠慮なく仲までお知らせください。


## 1. はじめに

このアプリは、これまで紙やメールで行っていた日報の作成・共有を、
スマートフォン・パソコンから直接行えるようにするものです。

- 訪問先・作業内容・使用部品・写真などをその場で記録できます
- 過去の日報を検索し、うまくいった対応事例や、注意すべき失敗事例を確認できます
- 管理者は全員分の日報を確認・管理できます


## 2. ログイン方法・アプリの入手方法

このアプリには「Web版」と「APK版(Androidアプリ)」の2種類があります。どちらも同じ機能が使えますが、入手方法が異なります。用途に合わせてお選びください。

### 🌐 Web版(ブラウザ / PWA)

ブラウザでURLを開くだけで使えます。ホーム画面に追加すればアプリのように起動できます。ストア不要・すぐ使えるのが特徴です。ホーム画面のアイコン名は **「日報アプリ(Web)」** と表示されます。

![Web版アクセス用QRコード](icons/web_download_qr.png)

📷 スマホのカメラで上のQRコードを読み取ってください

**アクセスURL: https://sn-report.web.app/**

### 🤖 APK版(Androidアプリ)

Androidの正式インストールアプリです。ホーム画面のアイコン名は **「日報アプリ」**(Web表記なし)です。
スマホで下のQRコードを読み取るか、下記URLからAPKファイルをダウンロードしてインストールしてください。

![APKダウンロード用QRコード](icons/apk_download_qr.png)

📷 スマホのカメラで上のQRコードを読み取ってください

**ダウンロードURL: https://sn-report.web.app/downloads/app-release.data**(ファイルサイズ約22MB)

> ※ インストール時に「不明なアプリのインストールを許可」を求められる場合があります。社内配布アプリのため許可して進めてください。
> ※ iPhoneではAPK版は利用できません(Androidアプリのため)。Web版をお使いください。

**🤖 APK版インストール後の開き方**

1. ダウンロード完了の通知(画面上部)をタップします。通知が消えた場合は、ブラウザの「ダウンロード」一覧、または端末の「ファイル」アプリから **app-release.apk** を探してタップします。
2. ファイルを開く際、アプリの選択画面が表示されたら **「パッケージインストーラー」**(端末によっては「インストーラー」「Package installer」と表示)を選んでください。
3. 「このアプリの提供元は不明です」という警告が出た場合は、**「詳細設定」→「このソースを許可」→「インストール」** の順に進んでください(社内配布アプリのため問題ありません)。
4. インストール完了後、**「開く」** ボタンを押すか、ホーム画面に追加された **「日報アプリ」** アイコンをタップして起動します。

> 💡 **どちらを選べばいい?** 特にこだわりがなければ、Web版で十分です。アップデートも自動で反映されるため、通常はWeb版の利用をおすすめします。

### 📲 Web版をスマホのホーム画面に追加する方法(推奨)

**Androidをお使いの方**
Chromeで上記URLを開くと、画面下に「インストール」ボタンが自動で表示されます。タップするだけでホーム画面に追加されます。
表示されない場合は、右上の「⋮」メニューを開き、「アプリをインストール」または「ホーム画面に追加」を選んでください。

**iPhone(Safari)をお使いの方**
Safariで上記URLを開き、画面下(または上)の共有ボタン「□↑」をタップします。
表示されたメニューから「ホーム画面に追加」を選び、右上の「追加」をタップすると完了です。
※ Chromeなど他のブラウザではこの手順は使えません。Safariでお試しください。

### ログイン手順

1. 上記URLをブラウザで開きます
2. 「メールアドレス」欄に、ご自身に割り当てられたメールアドレスを入力します
3. 「パスワード」欄に、お伝えした初期パスワードを入力します
4. 「ログイン」ボタンを押します

> ログインできない場合は、メールアドレス・パスワードに余分な空白が入っていないかご確認ください。
> 解決しない場合は仲までご連絡ください。


## 3. 【重要】初回ログイン後、パスワードの変更をお願いします

初期パスワードは全員が推測しやすい形式(社員番号+電話番号の一部)になっているため、
セキュリティ上、初回ログイン後にご自身のパスワードに変更してください。

**変更手順:**
1. 画面下の「プロフィール」タブを開く
2. 「パスワードを変更する」を選択
3. 新しいパスワード(6文字以上)を入力し、確認用にもう一度入力
4. 「変更する」を押す

パスワードは他人に推測されにくいもの(誕生日や電話番号そのままは避ける)にしてください。


## 4. 画面の基本構成

画面下部に4つのタブがあります(管理者のみ4つ、一般の方は3つ表示されます)。

| タブ | 内容 |
|---|---|
| ホーム | 本日・今月の日報件数、最近の日報一覧、日報作成ボタン |
| 検索 | 過去の日報をキーワードや事例の種類で検索 |
| 管理(管理者のみ) | 社員一覧・全日報の管理 |
| プロフィール | 自分の情報確認、パスワード変更、更新履歴・マニュアルの閲覧、ログアウト |

**プロフィール画面からできること**

プロフィール画面には、パスワード変更のほかに以下の項目があります。

- 📖 **入力マニュアル** — 現場でのルール(冷媒入力・コンビニ側入力控えなど)をアプリ内でいつでも確認できます。本マニュアルの要点をまとめたものです。
- 🕘 **更新履歴** — アプリに加えた改良内容を一覧で確認できます。「今の反映内容が自分のスマホに届いているか」を確認したい場合は、まずここで最新バージョンをチェックしてください。

**管理者の権限について(2階層)**

管理者権限は「一般管理者」「最高管理者」の2階層に分かれています。

| 役割 | できること |
|---|---|
| 一般管理者 | 管理ダッシュボードの閲覧、一般作業員の追加 |
| 最高管理者(社長など) | 上記に加え、社員の役割変更・削除など全ての管理操作 |

> 一般管理者は、誤操作・権限乱用の事故防止のため、他人への管理者権限の付与/剥奪や社員の削除はできません。これらの操作は最高管理者のみ行えます。


## 5. SE店舗とプロワン案件の入力ルールについて

現場は大きく「SE店舗(コンビニ)」と「SE以外のプロワン管轄案件」に分かれ、
**対応区分によって入力する内容が変わります。** 誤った入力方法だと社内データとして
正しく蓄積されませんので、必ず以下のルールに従って入力してください。

**なぜ入力方法が分かれているのか**

- SE店舗の報告書の提出先は、幹事会社が指定するコンビニ側の業務システムです。
- そのコンビニ側システムはデータを外部に抽出できないため、修理対応の内容を
  社内にも残すために、本アプリに「コンビニ側システム入力控え」として同じ内容を
  項目別に記録する設計にしています。
- 点検作業や、SE以外のプロワン管轄案件は、コンビニ側システムへの入力対象では
  ないため、基本情報の入力のみで完了します。

**入力ルール(フロー)**

```
                  対応する現場は?
                        │
        ┌───────────────┴───────────────┐
        │                                │
     SE店舗(コンビニ)              SE以外(プロワン管轄案件)
        │                                │
   対応区分は?                    基本情報のみ入力
        │                        (コンビニ側入力控え 不要)
   ┌────┴────┐                          │
   │         │                    🎯 目的:ナレッジ共有
定期点検   修理・故障対応
   │         │
基本情報   基本情報 +
のみ入力   コンビニ側システム
(控え不要)  入力控え(必須)
   │         │
   └────┬────┘
        │
🎯 目的:データ収集 + ナレッジ共有
```

**まとめ表**

| 対象 | 対応区分 | 入力内容 | 目的 |
|---|---|---|---|
| SE店舗 | 修理・故障対応 | 基本情報 ＋ コンビニ側システム入力控え(必須) | データ収集 + ナレッジ共有 |
| SE店舗 | 定期点検 | 基本情報のみ | データ収集 + ナレッジ共有 |
| SE以外(プロワン管轄) | すべて | 基本情報のみ | ナレッジ共有 |

> 「コンビニ側システム入力控え」は、日報作成画面の下部に表示される専用の入力欄です。
> 受付No.・冷媒種類・処置内容・部品など、コンビニ側システムの入力項目と同じ項目に
> 分かれているので、自由記述ではなく該当する欄にそのまま入力してください。

**入力画面は自動で切り替わります**

店舗を選択すると、その店舗が「SE店舗(コンビニ)」か「プロワン管轄案件」かが
画面上部にバッジ(色つきのお知らせ表示)で自動的に表示されます。

- 🟧 オレンジのバッジ「SE店舗(コンビニ) − 修理・故障対応はコンビニ側入力控えが必須です」
- 🟦 青灰のバッジ「プロワン管轄案件 − 基本情報のみで入力完了します」

さらに、対応区分を「修理」または「故障対応」に変更すると、SE店舗の場合のみ
「コンビニ側システム入力控え」セクションが自動的に表示されます。それ以外の
対応区分(定期点検など)や、SE以外の店舗を選んだ場合は表示されず、入力欄を
探す必要はありません。**表示・非表示はシステムが自動判定するため、
どちらのケースか迷った場合は画面の表示に従ってください。**


## 6. 日報を作成する

1. 「ホーム」タブ右下の「日報作成」ボタンを押します
2. 以下の項目を入力します

**基本情報**
- 店舗・訪問先(店舗一覧から選択、または直接入力)
- 訪問日
- 開始時刻・終了時刻
- 対応区分(以下から選択)
  - 定期点検 / 故障対応 / 修理 / 新設・設置 / 事務 / 現場事務 / 倉庫作業 / 環境整備 / その他
- 機器型番(プロワン参照・分かる範囲で)
- プロワン管理番号(任意)
- 共同作業者(一緒に対応した人がいれば選択)

**作業内容**
- 作業内容(★必須項目です。何を行ったか具体的に記入してください)
- 使用部品(「追加」ボタンで部品名・数量・型番等を記録)
- 写真(「追加」ボタンで現場写真を添付)

**「記入サポート」で入力もれを防止**

作業内容欄の下に、ナレッジ共有に必要な情報が抜けないようチェックリスト形式の
「記入サポート」が自動で表示されます。**店舗区分・対応区分によって内容が変わり、
他の欄と重複する項目は表示されません。**

| ケース | 表示される記入サポート | ポイント |
|---|---|---|
| プロワン管轄案件(SE以外) | 記入サポート(プロワン管轄案件) | 修理・故障の詳細はプロワン側システムに記録済みのため、状況の概要・判断ポイント・引き継ぎ事項など気づきを中心に記載 |
| SE店舗・修理・故障対応 | 記入サポート(SE店舗・修理・故障対応) | 事象・原因・処置はこの下の「コンビニ側システム入力控え」に書くため、対応中に気づいたこと・工夫・アドバイスを中心に記載 |
| SE店舗・点検など | 記入サポート(SE店舗・点検など) | 点検箇所・状態確認結果・気になった点・引き継ぎ事項を記載 |

> つまり、**「すでに他の欄・他システムに書く内容」は記入サポートには出てきません。**
> 表示されている項目を参考に、抜けなく記入してください。

**音声入力(マイクボタン)で入力を効率化**

作業内容、うまくいったこと、課題・失敗、コンビニ側システム入力控えの各欄には、
右側に🎤(マイク)アイコンが付いています。タップすると音声入力が始まり、
話した内容がそのまま文字として入力されます。もう一度タップすると停止します。

> 端末やブラウザによっては音声入力が利用できない場合があります。その場合は
> 「この端末・ブラウザでは音声入力がご利用いただけません」と表示されますので、
> 通常のキーボード入力をご利用ください。

**コンビニ側システム入力控え(SE店舗の修理・故障対応のみ・必須)**
- 前セクション「5. SE店舗とプロワン案件の入力ルールについて」の通り、
  SE店舗の修理・故障対応の場合のみ入力してください。
- 弊社受付No.・冷媒種類・充填量・依頼内容・設備名称・メーカー・型式・
  処置内容・部位・詳細部位・事象・原因・交換部品(最大5点)・備考 の各項目に分けて入力します。
- ⚠️ **「冷媒種類」「充填量」は必須項目です。** 空欄のままでは保存できません。
  冷媒を充填していない場合は、冷媒種類に「NONE」、充填量に「0」と入力してください。
- ⚠️ **「冷媒種類」「充填量」は半角英数字のみ入力できます。** 全角文字(全角のアルファベット・数字・カタカナ等)を入力するとエラーになりますので、日本語入力(IME)をオフにしてから入力してください。
  - 例:○「R410A」「1.5」 ×「Ｒ４１０Ａ」「１．５」

**ナレッジ共有(社内の知識として蓄積する項目)**
- うまくいったこと・工夫した点
- 課題・失敗・改善点
- タグ(症状・機種名など、後で検索しやすいキーワード)

3. 入力が終わったら保存します

> 「うまくいったこと」「課題・失敗」の欄は、社内のノウハウ共有・マニュアル改善のために活用されます。
> 些細なことでも構いませんので、気づいた点を記録していただけると助かります。


## 7. 日報を見る・編集する・削除する

- 「ホーム」または「検索」から一覧を開き、日報をタップすると詳細が見られます
- **自分が作成した日報**は編集・削除ができます
- 管理者は、必要に応じて他の人が作成した日報も削除できます(内容の編集は本人のみ)


## 8. 日報を検索する

「検索」タブから、キーワード検索に加えて次の絞り込みができます。
- 「うまくいった事例」だけを見る
- 「失敗・課題事例」だけを見る

過去に似たトラブルがあったかどうかを調べる際にご活用ください。


## 9. 困ったときは

**Q. パスワードを忘れてしまった**
A. ログイン画面の「パスワードをお忘れの方」を押し、登録メールアドレスを入力してください。
　 パスワード再設定用のメールが届きます。

**Q. 「ログインに失敗しました」と表示される**
A. メールアドレス・パスワードに誤りがないか再度ご確認ください。
　 解決しない場合は、仲までご連絡ください。

**Q. アプリの動きがおかしい・エラーが出る**
A. 一度ブラウザを閉じて再度開き直してみてください。
　 それでも解決しない場合は、画面のスクリーンショットを添えて仲までご連絡ください。

**Q. アプリの改良が反映されているか確認したい**
A. 「プロフィール」タブ内の「更新履歴」を開き、最新バージョンの内容をご確認ください。
　 反映されていないと感じる場合は、一度ブラウザを閉じて再度開き直してみてください。
